# 건설현장 대시보드

공정·원가·품질·안전 4대 관리항목 현황을 한 화면에 보여주는 정적 HTML 대시보드입니다.

## 1. 현장개요
| 항목 | 내용 |
|---|---|
| 공사기간 | 2025-02-24 ~ 2026-12-19 |
| 도급액 | 5,360,776,269원 |

## 2. 실행 방법
설치는 필요 없습니다. `index.html`을 브라우저로 열면 됩니다(인터넷 연결 불필요).

## 3. 파일 구성
| 파일 | 용도 |
|---|---|
| `index.html` | 화면·차트 (수정 불필요) |
| `data/data.js` | **모든 데이터** — 이 파일만 수정 |

## 4. 데이터 교체 절차
1. `data/data.js`의 `progress`(공정률), `milestones`, `cost`, `quality`, `safety` 값을 실제 값으로 교체
2. 교체가 끝나면 `SAMPLE: true` → `false` (상단 샘플 경고띠 제거)
3. `project.baseDate`에 보고 기준일을 입력 (비워 두면 오늘 날짜 적용)

> 현재 공사기간·도급액을 제외한 수치는 모두 **샘플(가상값)** 입니다.

## 5. 산정 기준
- 공정 차이(%p) = 실적 누계 공정률 − 계획 누계 공정률
- EVM: BAC = 실행예산, PV = BAC × 계획 공정률, EV = BAC × 실적 공정률, AC = 실투입원가 누계
- SPI = EV ÷ PV, CPI = EV ÷ AC
- 상태 판정(정상·주의·경고) 기준값은 `thresholds`에 정의한 현장 내부 관리기준이며, 법정 기준이 아닙니다.
