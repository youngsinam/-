# 송산 마을어울림센터 건립공사 현장 대시보드

공정·원가·품질·안전 4대 관리항목 현황을 한 화면에 보여주는 정적 HTML 대시보드입니다.
`index.html`을 브라우저로 열면 됩니다(설치·인터넷 연결 불필요).

## 1. 파일 구성
| 파일 | 내용 | 갱신 방법 |
|---|---|---|
| `index.html` | 화면·차트 | 수정 불필요 |
| `data/schedule.js` | 예정공정표(Rev.3) 주간 계획 누계, 공종별 주간 보할 | 스크립트 자동 생성 |
| `data/billing.js` | 기성내역서(기성검사원·청구서·선급금·원가계산서·집계표) | 스크립트 자동 생성 |
| `data/site.js` | 현장개요, 기성 기준일, 실측 공정률, 관리기준, 품질·안전 | 직접 입력 |
| `tools/extract_data.py` | 엑셀 → JS 변환 | — |

## 2. 데이터 갱신 (기성 회차·공정표 개정 시)
```bash
pip install openpyxl
python3 tools/extract_data.py --schedule <예정공정표.xlsx> --billing <제n회_기성내역서.xlsx>
```
- 셀 주소는 현재 양식(예정공정표 Rev.3, 제6회 기성내역서) 기준입니다. 양식이 바뀌면 스크립트를 수정해야 합니다.
- `data/site.js`의 `billingCutoff`(기성 기준일)를 해당 회차 기준일로 바꿔야 합니다.

## 3. 산정 기준
1. 계획 공정률: 예정공정표 '네트워크' 시트 합계(직접비+간접비) 주간 누계, 일 단위 직선보간
2. 기성 기준 실적 공정률 = (누계 기성 − ES 누계) ÷ 공정표 보할 기준금액(5,286,187,269원)
3. 공정 차이 = 실적 − 계획, SPI = 실적 ÷ 계획
4. 공종별 계획 진도 = 기성 기준일까지 공종 주간 보할 합 ÷ 공종 총 보할, 기성 진도 = 누계 기성 ÷ 계약금액
5. 상태 판정 기준값(`thresholds`)은 현장 내부 관리기준이며 법정 기준이 아닙니다.

## 4. 현재 데이터 상태
- 공정: 예정공정표 Rev.3 (2026-04-20 작성) — 실제
- 원가: 제6회 기성내역서 (2026년 10월) — 실제
- 실측 공정률(주간공정보고): 미입력 — 추후 `data/site.js`의 `actualProgress`에 입력 (입력 전까지 기성 기준 실적 표시)
- 품질·안전: 미입력 — 추후 `data/site.js`의 `quality`, `safety`에 입력 (입력 전까지 "자료 미입력" 표시)
