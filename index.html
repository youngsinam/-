안전점검 지적사항

최근 지적순
산정 기준
  1. 계획 공정률: 예정공정표 '네트워크' 시트 합계(직접비+간접비) 주간 누계. 임의 일자의 계획값은 주간 누계 사이를 일 단위 직선보간
  2. 기성 기준 실적 공정률 = (누계 기성금액 − 물가변동(ES) 누계) ÷ 공정표 보할 기준금액. 기성은 청구 기준이므로 현장 실측 공정률과 다를 수 있으며, 실측값은 data/site.js 의 actualProgress 에 입력하면 우선 표시
  3. 공정 차이(%p) = 실적 − 계획 / SPI = 실적 공정률 ÷ 계획 공정률 (동일 기준일)
  4. 공종별 계획 진도 = 기성 기준일까지의 해당 공종 주간 보할 합 ÷ 해당 공종 총 보할 / 기성 진도 = 누계 기성 ÷ 계약금액
  5. 상태 판정(정상·주의·경고)은 data/site.js 의 thresholds 에 정의한 현장 내부 관리기준이며 법정 기준이 아님
  6. 품질시험 판정기준은 건설공사 품질관리 업무지침 및 해당 공종 KCS에 따름 (대시보드는 건수 집계만 수행)
